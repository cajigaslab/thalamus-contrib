Build
=====

The project is built by hatch.  The rust code has dependencies on projects that the hatch custom build hook manages
and directly invoking cargo build will fail.

FFI
===

The shared library that is generated by the rust project will be used by the thalamus-neuro python package.  The
source code is available at https://github.com/cajigaslab/Thalamus.git.  It will be loaded at runtime and the
get_node_factories function will be used to get functions to discover all of the nodes provided by this project.  This
discovery is implemented by the Thalamus project in src/thalamus/node_graph_impl.cpp.

Most users should only contribute rust code in rust/src/*_node.rs file which provide implementations of AnalogNode,
ImageNode, and MocapNode.  These nodes need to be declared in the export_nodes! macro in lib.rs in order to be loaded
by Thalamus.  The *_node.rs files should include no unsafe code.

Thalamus Versions
=================

The main code used to publish thalamus-neuro pip packages is in the main branch, the branch where most active work is
done is the devel branch.
